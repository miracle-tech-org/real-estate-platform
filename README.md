# Northline Realty

A full-featured real estate platform frontend built with **React + Vite + TypeScript**. All listing, agent, neighborhood, and blog content is **mock data**.

## Features

- Home hero search and featured listings
- Advanced listing search & filters
- Listing detail pages (gallery, inquiry, payment estimate, similar homes)
- Interactive mock map search
- Favorites and side-by-side compare (localStorage)
- Agents directory & profiles
- Neighborhood guides with scores
- Mortgage calculator
- Market insights blog
- Mock auth, buyer dashboard, and contact form

## Quick start

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Start Vite dev server    |
| `npm run build`| Typecheck + production build |
| `npm run preview` | Preview production build |

## Stack

- React 19
- Vite
- TypeScript
- React Router
